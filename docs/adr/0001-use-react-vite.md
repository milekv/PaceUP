# ADR 0001: Use React, TypeScript, and Vite

## Status

Accepted

## Context

PaceUP needs a fast frontend stack that is easy to deploy on GitHub Pages and easy to review on GitHub.

## Decision

Use React with TypeScript and Vite.

## Consequences

- Local development is simple.
- Static deployment is straightforward.
- TypeScript helps keep pace calculations reliable.
- Future data persistence can be added without changing the base app structure.
