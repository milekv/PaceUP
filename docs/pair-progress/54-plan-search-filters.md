# Plan Search Filters

Wydarzenia i aktywnosci grupowe beda potrzebowaly filtrow. Lepiej zaplanowac je
przed duza liczba danych, zeby uniknac przypadkowych pol w backendzie.

## Filtry

- typ aktywnosci,
- lokalizacja,
- data,
- poziom trudnosci,
- status wolnych miejsc,
- widocznosc publiczna albo ekipowa.
