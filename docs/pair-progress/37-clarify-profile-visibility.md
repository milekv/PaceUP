# Clarify Profile Visibility

Profil PaceUp powinien miec proste ustawienia widocznosci. Uzytkownik musi wiedziec,
czy inni widza jego aktywnosci, poziom, ekipy i wydarzenia.

## Widocznosc

- publiczny profil,
- profil tylko dla ekipy,
- prywatna historia aktywnosci,
- oddzielne ustawienie dla lokalizacji.
