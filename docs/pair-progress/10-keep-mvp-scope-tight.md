# Keep MVP Scope Tight

PaceUp powinien najpierw dowiezc prosty, powtarzalny cykl uzycia: start aktywnosci,
zapis wyniku, XP, quest i widoczny progres. Kazda nowa funkcja powinna wspierac ten
cykl albo zostac odlozona do roadmapy.

## Zasady

- nie dodawac ekranu bez jasnej akcji uzytkownika,
- nie rozbudowywac socialu przed stabilnym solo flow,
- utrzymac szybki onboarding i niski prog pierwszego treningu,
- traktowac integracje GPS jako rozszerzenie, nie warunek MVP.
