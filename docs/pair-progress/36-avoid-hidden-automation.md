# Avoid Hidden Automation

Automatyzacja moze przyspieszyc produkt, ale nie powinna robic zmian, ktorych
uzytkownik nie rozumie. Dotyczy to szczegolnie XP, planow i publikacji do feedu.

## Zasady

- pokazuj, kiedy system cos naliczyl,
- wymagaj potwierdzenia przed publikacja,
- nie zmieniaj celu treningowego bez zgody,
- zapisuj powod automatycznej decyzji.
