# Record Release Risks

Kazdy release powinien miec krotka notatke o ryzyku. Dzieki temu latwiej sprawdzic,
czy zmiana moze popsuc onboarding, XP albo zapis aktywnosci.

## Ryzyka

- migracje danych,
- zmiany w naliczaniu XP,
- nowe pola formularzy,
- publikacja aktywnosci do feedu,
- zmiany w ustawieniach prywatnosci.
