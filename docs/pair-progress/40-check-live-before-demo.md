# Check Live Before Demo

dzialajaca aplikacje live.

## Checklist

- live URL otwiera sie bez przekierowan,
- ekran startowy laduje sie na telefonie,
- glowne przyciski sa widoczne,
- README wskazuje aktualny adres aplikacji.
