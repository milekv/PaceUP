# Keep XP Auditable

XP powinno byc mozliwe do odtworenia z historii zdarzen. To chroni produkt przed
sytuacja, w ktorej wynik na profilu nie zgadza sie z aktywnosciami.

## Zasady

- zapisuj zdarzenie XP osobno od aktywnosci,
- przechowuj powod naliczenia punktow,
- trzymaj timestamp i id powiazanej aktywnosci,
- nie nadpisuj historii bez migracji.
