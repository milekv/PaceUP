# Define Data Ownership

PaceUp powinien miec jasne zasady, kto moze zmieniac dane aktywnosci, profilu i
ekipy. To ulatwia pozniejszy backend i ogranicza przypadkowe nadpisywanie danych.

## Zasady

- uzytkownik edytuje wlasny profil,
- aktywnosc ma jednego wlasciciela,
- ekipa ma role z konkretnymi uprawnieniami,
- operacje admina trafiaja do audytu.
