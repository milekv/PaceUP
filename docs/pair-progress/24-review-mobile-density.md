# Review Mobile Density

PaceUp jest mobile-first, wiec ekran startowy musi byc gesty informacyjnie, ale nie
moze byc chaotyczny. Najwazniejsze dane powinny byc widoczne bez dlugiego szukania.

## Kontrola

- poziom, XP i plan dnia sa wysoko,
- karty maja stale wymiary,
- tekst nie wypada poza przyciski,
- akcje treningowe sa latwe do trafienia kciukiem.
