# Design Streak Recovery

Streak moze motywowac, ale nie powinien karac za jedna przerwe. PaceUp powinien
wspierac powrot do ruchu, a nie tylko idealna regularnosc.

## Kierunek

- pokazuj historie bez zawstydzania,
- pozwol odbudowac streak,
- odrozniaj odpoczynek od porzucenia planu,
- dawaj quest powrotowy po przerwie.
