# Separate Admin Views

Panel administracyjny powinien miec osobny model uprawnien. Nie warto mieszac
moderacji, metryk produktu i zwyklego profilu uzytkownika w jednym przeplywie.

## Zakres admina

- przeglad zgloszen,
- status wydarzen,
- podstawowe metryki zdrowia produktu,
- audyt zmian w danych krytycznych.
