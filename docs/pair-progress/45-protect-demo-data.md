# Protect Demo Data

Dane demonstracyjne powinny wygladac realistycznie, ale nie moga udawac prawdziwych
osob ani ujawniac prywatnych lokalizacji.

## Standard

- fikcyjne imiona i aktywnosci,
- neutralne miejsca,
- brak prawdziwych numerow kontaktowych,
- latwa wymiana seed data przed publicznym demo.
