# Plan Offline State

Uzytkownik moze trenowac poza stabilnym zasiegiem. Nawet jesli pelny offline mode nie
jest w MVP, aplikacja powinna miec plan na utrzymanie danych.

## Priorytet

- zachowaj formularz lokalnie,
- pokaz status synchronizacji,
- nie blokuj podsumowania treningu,
- unikaj podwojnego naliczania XP po powrocie sieci.
