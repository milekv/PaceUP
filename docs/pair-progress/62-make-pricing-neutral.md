# Make Pricing Neutral

Jesli PaceUp kiedykolwiek doda platne funkcje, core progresu powinien nadal dzialac
uczciwie dla darmowego uzytkownika.

## Granice

- podstawowy zapis aktywnosci zostaje darmowy,
- prywatnosc nie jest funkcja premium,
- platne funkcje nie moga kupowac XP,
- analityka zaawansowana moze byc rozszerzeniem.
