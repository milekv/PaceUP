# Keep Docs Current

Dokumentacja PaceUp jest czescia produktu. Gdy zmienia sie flow, dane albo decyzja
techniczna, docs powinny zmieniac sie razem z kodem.

## Standard

- README opisuje aktualny produkt,
- docs trzymaja decyzje i checklisty,
- changelog pokazuje widoczne zmiany,
- stare notatki maja zostac oznaczone albo zaktualizowane.
