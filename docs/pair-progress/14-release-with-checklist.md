# Release With Checklist

Kazdy release PaceUp powinien miec krotka liste kontrolna. To pomaga utrzymac jakosc,
nawet gdy projekt rozwija sie szybko.

## Przed wydaniem

- uruchomic lint i build,
- sprawdzic ekran startowy na mobile,
- przejsc onboarding od zera,
- sprawdzic zapis aktywnosci solo,
- potwierdzic link do live app,
- dopisac widoczna zmiane do changeloga.
