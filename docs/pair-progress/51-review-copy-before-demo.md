# Review Copy Before Demo

Teksty w aplikacji powinny byc sprawdzone przed kazdym demo. Nawet dobra funkcja
wyglada slabiej, gdy etykiety sa niespojne albo zbyt techniczne.

## Kontrola

- przyciski maja czasowniki akcji,
- puste stany mowia co dalej,
- bledy sa konkretne,
- nazwy questow sa krotkie,
- README pokazuje aktualny opis produktu.
