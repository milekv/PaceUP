# Prepare Import Paths

W przyszlosci uzytkownicy moga chciec przeniesc historie z innych narzedzi. Nie trzeba
tego budowac od razu, ale model danych powinien zostawic miejsce na import.

## Kandydaci

- reczny wpis aktywnosci,
- import pliku treningowego,
- integracja z zegarkiem,
- laczenie duplikatow po czasie i typie aktywnosci.
