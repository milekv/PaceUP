# Keep Quest Copy Clear

Questy maja motywowac, nie tlumaczyc system. Tekst powinien byc krotki, konkretny i
zwiazany z akcja, ktora uzytkownik moze wykonac dzisiaj.

## Przyklady zasad

- uzywaj czasownikow akcji,
- pokazuj licznik postepu,
- unikaj zargonu technicznego,
- wyjasniaj nagrode tylko wtedy, gdy jest potrzebna.
