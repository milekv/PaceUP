# Guard Public Events

Publiczne wydarzenia sportowe moga przyciagac nowych ludzi, ale wymagaja prostych
barier bezpieczenstwa i moderacji.

## Wymagania

- opis wydarzenia z limitem dlugosci,
- godzina i miejsce w czytelnym formacie,
- mozliwosc zgloszenia wydarzenia,
- brak publikacji prywatnych danych uczestnikow.
