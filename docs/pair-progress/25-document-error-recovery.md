# Document Error Recovery

Blad zapisu aktywnosci jest krytyczny, bo uzytkownik mogl wlasnie skonczyc realny
trening. Aplikacja powinna jasno pokazac, co zostalo zachowane.

## Minimum

- nie trac notatek z formularza,
- pokaz mozliwosc ponowienia zapisu,
- rozdziel blad sieci od bledu walidacji,
- nie naliczaj XP podwojnie po retry.
