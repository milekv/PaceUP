# Simplify Notification Rules

Powiadomienia powinny pomagac w regularnosci, ale nie moga byc glosniejsze niz sam
produkt. Domyslne ustawienia musza byc ostrozne.

## Zasady

- przypominaj o planie dnia,
- nie wysylaj zbyt wielu social nudges,
- pozwol wyciszyc ekipy,
- grupuj mniej pilne informacje.
