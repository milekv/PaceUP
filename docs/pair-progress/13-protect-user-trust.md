# Protect User Trust

Aplikacja fitness dotyka danych o rutynie, lokalizacji i zdrowiu. PaceUp powinien byc
projektowany tak, aby uzytkownik zawsze rozumial, co jest prywatne, a co publiczne.

## Standard

- domyslnie prywatna historia aktywnosci,
- jasne potwierdzenie przed publikacja do feedu,
- brak publicznego udostepniania lokalizacji bez zgody,
- proste ustawienia widocznosci profilu i aktywnosci.
