# Review Analytics Privacy

Analityka produktu powinna pomagac rozwijac PaceUp bez zbierania nadmiarowych danych
o zyciu uzytkownika.

## Zasady

- licz zdarzenia produktowe, nie prywatne trasy,
- agreguj dane tam, gdzie to mozliwe,
- nie wysylaj notatek treningowych do analityki,
- dokumentuj cel kazdego eventu.
