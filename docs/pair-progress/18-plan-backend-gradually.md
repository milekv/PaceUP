# Plan Backend Gradually

Backend powinien rosnac razem z produktem. Najpierw trzeba utrwalic model danych i
reguly XP, dopiero potem dokladac funkcje wymagajace wiekszej synchronizacji.

## Kolejnosc

- profil i preferencje,
- historia aktywnosci,
- XP ledger,
- quest progress,
- ekipy i wydarzenia,
- powiadomienia i zaproszenia.
