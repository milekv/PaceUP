# Plan Goal Editing

Cele treningowe powinny byc mozliwe do zmiany bez utraty historii. Uzytkownik moze
zmienic plan, ale poprzednie aktywnosci nadal musza miec sens.

## Kierunek

- przechowuj wersje celu,
- nie przeliczaj historii bez powodu,
- pokaz date zmiany celu,
- pozwol wrocic do poprzedniego tempa.
