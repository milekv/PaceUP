# Make Social Optional

Warstwa spolecznosciowa ma wzmacniac motywacje, ale nie moze blokowac wartosci
produktu. Uzytkownik powinien czuc progres nawet wtedy, gdy trenuje sam.

## Decyzje produktowe

- feed nie jest pierwszym wymaganym krokiem,
- questy solo dzialaja bez ekipy,
- ekipy daja bonus kontekstowy, nie warunek postepu,
- wydarzenia lokalne moga byc puste bez psucia glownego doswiadczenia.
