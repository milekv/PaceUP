# Events and Race Mode

Events should connect solo training with local community goals.

## Event Cards

An event card should make the basics scannable:

- name,
- location,
- date and time,
- activity type,
- difficulty,
- participant count,
- related quest or plan.

## Race Mode

Race mode should help users prepare without turning PaceUP into a pure race tracker.

- Connect a plan to a target event.
- Show progress toward race readiness.
- Encourage group preparation when teams exist.
- Keep GPS and route tracking as a focused future milestone.

## Safety

- Do not expose private location history.
- Avoid showing exact user routines publicly.
- Keep event participation reversible where possible.
