# Analytics Metrics

Analytics should help users understand progress, not punish them for imperfect weeks.

## Core Metrics

- completed activities,
- active minutes,
- running and cycling distance,
- strength volume,
- XP earned,
- streak,
- plan completion,
- favorite activity type.

## Product Rules

- Compare users to their own history before comparing them to others.
- Keep weekly and monthly views easy to scan.
- Explain empty analytics states with a useful next action.
- Separate strength volume from distance-based activities.
