# Issue Triage

Issues should be easy to sort by product impact.

## Labels

- `bug` for broken behavior,
- `feature` for new product scope,
- `docs` for documentation changes,
- `design` for UI and UX decisions,
- `backend` for persistence and service work,
- `qa` for testing and verification.

## Priority Signals

- blocks login,
- breaks activity completion,
- duplicates XP,
- exposes private data,
- affects mobile primary actions,
- causes production deployment failure.
