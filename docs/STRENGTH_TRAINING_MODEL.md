# Strength Training Model

Strength training needs its own structure instead of borrowing running metrics.

## Workout Data

- workout type,
- target muscle groups,
- exercises,
- sets,
- reps,
- weight,
- optional RPE,
- total volume.

## UX Rules

- Make logging fast during a workout.
- Keep previous set values easy to repeat.
- Show volume summaries after completion.
- Let strength workouts count toward quests and XP.
