# Maintainer Notes

These notes keep PaceUP changes focused as the project grows.

## Keep

- small PRs,
- clear docs,
- mobile-first review,
- simple data boundaries,
- explicit follow-up tasks.

## Avoid

- mixing product scope and refactors,
- committing secrets,
- adding heavy dependencies without a reason,
- hiding unfinished behavior in UI copy,
- shipping social features without privacy review.
