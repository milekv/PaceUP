# Activity Taxonomy

PaceUP supports multiple activity types, so each type should use metrics that make sense for the user.

| Activity | Primary Metrics | Notes |
| --- | --- | --- |
| Running | distance, time, pace | Best for plans, race prep, and pace goals. |
| Walking | time, optional distance | Low-pressure progress and habit building. |
| Cycling | distance, time, speed | Should not reuse running pace language. |
| Trekking | distance, time, elevation, difficulty | Outdoor-focused, slower by nature. |
| Strength | exercises, sets, reps, weight, RPE, volume | No distance or pace required. |
| Social | place, time, people, note | Supports community without sport pressure. |

## Product Rules

- Do not force every activity into distance and pace.
- Keep optional metrics optional.
- Show activity-specific summaries after completion.
- Let plans and quests target the activity type directly.
- Keep social activities lightweight and welcoming.
