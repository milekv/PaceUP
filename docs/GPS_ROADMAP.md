# GPS Roadmap

GPS should be introduced when the product flow around activities is stable.

## Milestones

1. Permission handling and fallback states.
2. Start, pause, resume, and finish tracking.
3. Distance and pace calculation.
4. Route summary after completion.
5. Map visualization.
6. Battery and background behavior testing.

## Safety

- Do not expose live routes publicly by default.
- Let users discard accidental recordings.
- Keep location permission language clear.
