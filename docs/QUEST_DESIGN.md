# Quest Design

Quests should help users build consistency without turning every action into pressure.

## Quest Types

- daily movement,
- weekly consistency,
- solo progress,
- team activity,
- event preparation,
- strength training.

## Rules

- Keep quest goals measurable.
- Show progress before completion.
- Avoid repeating the same reward action.
- Let quests support different activity types.
- Prefer healthy consistency over extreme volume.
