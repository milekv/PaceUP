# Dashboard Guidelines

The dashboard should make the next useful action obvious.

## Priorities

- Show level, XP, streak, and plan progress without clutter.
- Keep the primary action visible on mobile.
- Surface today's workout or quest before long-term analytics.
- Make solo and social options equally clear.

## Content Rules

- Use short labels for metrics.
- Keep reward language encouraging, not overwhelming.
- Avoid showing empty charts when the user has no data.
- Link deeper views only after the summary is understandable.
