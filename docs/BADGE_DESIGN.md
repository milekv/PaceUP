# Badge Design

Badges should feel earned, clear, and tied to meaningful behavior.

## Badge Categories

- consistency,
- first milestones,
- activity diversity,
- team participation,
- event preparation,
- strength progress.

## Design Rules

- Badge names should be short and memorable.
- Unlock criteria should be explainable in one sentence.
- Rare badges should require repeated behavior.
- Badge unlocks should not block the next product action.
