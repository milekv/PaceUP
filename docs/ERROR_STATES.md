# Error States

Error states should help users recover without making the app feel broken.

## Common Errors

- expired session,
- failed profile load,
- failed activity save,
- duplicated XP event,
- unavailable event details,
- slow or offline network.

## Copy Rules

- Say what happened in plain language.
- Offer one clear next action.
- Avoid exposing internal database or API details.
- Keep destructive retry actions explicit.
