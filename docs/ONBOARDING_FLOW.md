# Onboarding Flow

Onboarding should help a new user reach their first useful action quickly.

## Goals

- Explain PaceUP without a long tutorial.
- Collect only the preferences needed for a better first dashboard.
- Let the user choose solo progress, social activity, or both.
- Avoid blocking exploration when optional data is missing.

## Suggested Steps

1. Create account or sign in.
2. Pick primary activity interests.
3. Choose current goal: consistency, first race, strength, health, or social training.
4. Set a lightweight weekly target.
5. Land on the start dashboard with one obvious next action.

## First Success Moment

The first session should guide the user toward one of these outcomes:

- start a solo activity,
- join or inspect a group activity,
- select a training plan,
- complete a simple quest,
- customize profile basics.
